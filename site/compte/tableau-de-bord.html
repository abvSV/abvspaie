Clés API marchand

Pas de clé API marchand disponible actuellement.ABVSPAIE ne propose pas encore d'API serveur pour créer des paiements depuis votre backend. Aucune clé secrète n'est générée ni stockée depuis cette page.

La clé Supabase publique utilisée par le site n'est pas une clé API privée pour votre intégration : ne l'utilisez jamais avec un rôle serveur et ne placez jamais une clé service_role dans le navigateur. Les accès du tableau de bord restent protégés par l'authentification et les politiques RLS.

Intégrer un paiement

La méthode disponible est le lien de paiement hébergé ABVSPAIE. Le client choisit son moyen de paiement et confirme sur la page sécurisée.

  1. Créez un lien dans Liens de paiement et copiez son identifiant (slug).
  2. Construisez l'URL ci-dessous pour votre bouton ou votre page de commande.
  3. Vérifiez les paiements depuis Transactions. Les liens en mode test simulent le résultat et ne transfèrent pas de fonds.
